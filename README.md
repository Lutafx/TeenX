# 🦄 TeenX Hub - Telegram Bot

Улучшенный Telegram бот для платформы TeenX с автоматическими уведомлениями и синхронизацией с Firebase.

## 🚀 Новые возможности

### ✨ Для пользователей:
- **🔔 Автоматические уведомления** - Мгновенные оповещения о новых вакансиях
- **📋 Синхронизация с сайтом** - Вакансии загружаются напрямую из Firebase
- **👤 Управление подпиской** - Включай/выключай уведомления одной кнопкой
- **🛡️ Юридическая помощь** - Информация о правах подростков
- **📱 Прямые ссылки на WhatsApp** - Откликайся на вакансии в один клик

### 🛡️ Для админа:
- **📊 Статистика в реальном времени** - Подписчики, вакансии, верификации
- **👥 Модерация верификаций** - Одобряй/отклоняй документы прямо в боте
- **📢 Рассылка** - Автоматическая отправка новых вакансий всем подписчикам
- **🔍 Мониторинг** - Бот проверяет новые вакансии каждую минуту

## 📦 Установка

1. **Установи зависимости:**
```bash
pip install -r requirements.txt
```

2. **Настрой Firebase:**
   - Скачай `serviceAccountKey.json` из Firebase Console
   - Замени `FIREBASE_CONFIG` в `bot.py` на данные из файла

3. **Запусти бота:**
```bash
python bot.py
```

## ⚙️ Конфигурация

### Firebase Setup:
1. Зайди в [Firebase Console](https://console.firebase.google.com/)
2. Выбери проект `teenx-hub`
3. Settings → Service Accounts → Generate New Private Key
4. Скачай JSON и вставь данные в `FIREBASE_CONFIG`

## 🔄 Интеграция с сайтом

### Что синхронизируется:
1. **Вакансии** - Загружаются из Firestore (`jobs` collection)
2. **Верификации** - Пользователи с `verified: 'pending'`
3. **Статусы** - Обновления верификации сохраняются в Firebase

### Как это работает:
```
Сайт (Firebase) ←→ Бот (Firebase Admin SDK)
     ↓                      ↓
  Создание вакансии → Уведомление в Telegram
  Загрузка документа → Отправка админу
  Одобрение в боте → Обновление на сайте
```

## 🐛 Решение проблем

### Firebase не подключается:
1. Проверь `serviceAccountKey.json`
2. Убедись что `project_id` = `teenx-hub`
3. Проверь права доступа в Firebase Console

### Уведомления не приходят:
1. Проверь что бот запущен
2. Убедись что `/start` был нажат
3. Проверь что уведомления включены (кнопка 🔔)

### Бот не видит вакансии:
1. Проверь что в Firestore есть вакансии со `status: 'active'`
2. Проверь подключение к Firebase
3. Посмотри логи в консоли
