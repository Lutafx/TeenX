# TeenX Hub - Web Application

Современная платформа для легального трудоустройства подростков 14-18 лет в Казахстане.

## 🚀 Возможности

### Для подростков:
- 📋 Просмотр вакансий с детальной информацией
- 💰 Прозрачные условия оплаты (от 50,000₸ до 400,000₸)
- 📱 Отклик на вакансии с указанием телефона
- 📄 Готовые шаблоны документов для трудоустройства
- 🛡️ Защита прав несовершеннолетних
- ⚠️ Автоматическая проверка возраста при отклике

### Для работодателей:
- ➕ Добавление вакансий через удобную форму
- 📊 Детальное описание условий работы
- 📞 Прямая связь с кандидатами через WhatsApp
- ✅ Модерация вакансий администратором

### Для администратора:
- 🔍 Модерация вакансий перед публикацией
- 👥 Верификация пользователей
- 📊 Статистика платформы
- 🤖 Интеграция с Telegram ботом

## 🛠️ Технологии

- **Frontend**: React 18, React Router
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Backend**: Firebase (Firestore, Authentication, Storage)
- **Build Tool**: Vite

## 📦 Установка

1. Установите зависимости:
```bash
cd web
npm install
```

2. Настройте Firebase:
   - Создайте проект в [Firebase Console](https://console.firebase.google.com)
   - Скопируйте конфигурацию в `src/firebase.js`

3. Запустите dev сервер:
```bash
npm run dev
```

4. Откройте http://localhost:3000

## 📋 Основные страницы

### Главная страница
- Hero секция с призывом к действию
- Преимущества платформы
- Разделы для подростков и работодателей

### Страница вакансий
- Фильтрация по возрасту (14-16, 16-18)
- Карточки с основной информацией
- Переход на детальную страницу

### Детальная страница вакансии
- **Выделенная зарплата** с диапазоном
- Условия работы (график, занятость, формат)
- Описание компании
- Обязанности и требования
- Форма отклика с проверкой возраста
- Кнопка WhatsApp для связи

### Добавление вакансии
- Полная форма с всеми деталями
- Автоматическая отправка на модерацию
- Уведомление админа в Telegram

### Документы
- Разделение по возрастам (14-16 и 16-18)
- Список необходимых документов
- Шаблоны для скачивания
- Информация о правах подростков

### Админ-панель
- Статистика платформы
- Модерация вакансий
- Верификация пользователей
- Кнопки одобрения/отклонения

## 🔐 Безопасность
